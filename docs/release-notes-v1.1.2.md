# SlotBridge 1.1.2 (6)

Bugfix release for mobile AI and profile UI.

- Fixed AI quick-action hit testing and kept actions accessible while scrolling.
- Added visible loading, cold-start messaging, transient-error retry, and clearer fallback UI.
- Increased production network timeouts for Render cold starts.
- Fixed the edit-profile form layout, including the read-only email field.
- Improved small-screen, keyboard, and dark-theme behavior.

No new product features or architecture changes are included.
