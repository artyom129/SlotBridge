# SlotBridge 1.1.1 (5)

Bugfix release focused on mobile UI stability and polish.

- Improved SlotBridge AI loading, retry, confirmation, scrolling, and keyboard behavior.
- Prevented repeated actions while network requests are in progress.
- Fixed layout issues for small screens, long names, and dark theme.
- Improved error handling in booking, profile, waitlist, and appointment screens.

No new product features or architecture changes are included.
