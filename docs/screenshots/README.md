# Screenshots

В репозитории пока нет актуальных screenshots приложения. Поддельные или
сгенерированные изображения не добавляются.

Перед защитой можно сделать снимки реального Android-приложения и сохранить их
в этой папке:

- home.png — главный экран;
- booking.png — выбор услуги, сотрудника и времени;
- appointments.png — My Appointments;
- ai.png — SlotBridge AI без персональных данных;
- journey.png — три стратегии Multi-Service Smart Journey;
- profile.png — профиль, язык, тема и проверка обновлений.

Перед commit проверьте, что на изображениях нет JWT, email реальных
пользователей, API keys, database URL, телефонных номеров или других
персональных данных. После добавления настоящих файлов их можно встроить в
корневой README.
